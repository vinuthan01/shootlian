# SHOOTLIAN

A browser arcade shooter by Vinuthan (`vinuthan01`). No build step or server required.

## Play

Open `index.html` in a modern browser.

- Aim with your cursor; hold the left mouse button to fire.
- Right-click, `P`, or `Esc` pauses the game.
- On touch screens, tap and drag to aim and fire. Mobile shots travel more slowly for easier tracking.
- Choose one permanent run upgrade after defeating each boss.
- Use **SOUND ON/OFF** in the header to mute or unmute. Audio starts after the first gameplay click or tap because browsers block autoplay.

## Features

- Three alien types, combo multipliers, and near-miss bonuses.
- A boss encounter every 10 kills, with a health bar and attack volleys.
- Boss rewards and six upgrade types: faster fire, plasma damage, extra barrels, hull repair, longer combos, and bonus score.
- Personal-best shot-color unlocks, saved in the browser.
- Original ambient music and game effects synthesized with Web Audio. No audio files or external music licenses are required.

## Publish with GitHub Pages

1. Add the files in this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. Save and wait for GitHub Pages to publish the site.
